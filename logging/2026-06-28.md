# 2026-06-28 改进记录

## LG-FrankenMotion 方案落地

- 阅读 `LG_FrankenMotion方案管理/LG-FrankenMotion.docx`，确认本阶段目标为在 FrankenMotion 的 part-level text-to-motion 基础上加入 local-global coordination。
- 在 `src/model/backbones/frankenmotion.py` 中新增 `LGTransformerDenoiser`，保留原 `TransformerDenoiser` 以兼容旧 checkpoint。
- 新模型包含以下模块：
  - Shared motion / condition embedding
  - Part Local Branch
  - Global Coordination Branch
  - Part-to-Global Attention
  - Global-to-Part Attention
  - Coordination Gate
  - Temporal Coordination Refine residual TCN
- 在 `configs/frankenmotion.yaml` 中将默认 denoiser 切换为 `LGTransformerDenoiser`，并补充 motion/text part 维度和部件顺序配置。
- 已用假 batch 验证新 denoiser forward，输出形状保持 `[B, T, 613]`，兼容现有 diffusion 训练与采样接口。

## 训练统计阶段内存优化

- 服务器 31GB 容器运行 base 训练时，`train_part.py` 的统计阶段会把全量 motion/text embedding 一次性堆到内存中，导致内存爆掉。
- 将 `save_masked_stats` 从全量 `append + torch.cat` 改为流式累计：
  - `sum`
  - `sumsq`
  - `count`
- motion 和 local text 使用 masked streaming stats。
- global text 使用 unmasked streaming stats。
- 加入 `finally`，确保统计阶段异常时也会恢复 `dataset.is_training`。
- 已用 dummy dataset 验证 mean/std 维度正确，并通过语法检查。
