## Part-Level Semantic Alignment 定位

- 单独检查 part-level semantic alignment 是否已经解决。
- 当前代码中已有：
  - part-level text embedding 与 motion 时间帧对齐；
  - part-wise evaluation，包括 Part R@1 / R@3 / M2T retrieval 等指标；
  - `EvalInTraining` 中可监控 `avg_part_R1`。
- 当前代码中没有把 `L_part-align = Contrastive(z_part_motion, z_part_text)` 接入生成模型训练。
- 从论文叙事角度判断：LG-FrankenMotion 的主线应聚焦 local-global coordination，不应把 part semantic alignment loss 包装成新的主要贡献。
- 推荐定位：
  - part alignment 作为 controllability preservation / evaluation；
  - 不作为 LG-FrankenMotion 的核心创新点；
  - 如实验发现 LG coordination 降低 Part R@1 / R@3，再启用轻量保护项。

## 新增可配置 Part Preserve Loss

- 在 `configs/frankenmotion.yaml` 中新增默认关闭配置：

```yaml
diffusion:
  part_preserve_loss_weight: 0.0
  part_preserve_motion_featsname: ${motion_features}
```

- 在 `src/model/backbones/frankenmotion.py` 中保存 `motion_featsname`，便于 diffusion loss 侧按 motion feature 类型读取 body-part 特征索引。
- 在 `src/model/gaussian.py` 中为 `GaussianDiffusion` 增加轻量 `part_preserve_loss`：
  - 只在 `part_preserve_loss_weight > 0` 时启用；
  - 使用 `stats_mask` 判断某个 body part 在某些帧是否存在有效 prompt；
  - 根据 `src.bptools.get_indexes_body_parts()` 获取对应 body part 的 motion feature slice；
  - 只对有效 prompt 对应的 body-part motion 特征额外计算 MSE；
  - 不引入新的 retrieval encoder、contrastive branch 或额外模型依赖。
- 启用后总 loss 形式为：

```text
loss = diff_loss + part_preserve_loss_weight * part_preserve_loss
```

- 启用后训练日志会额外记录：
  - `train_diff loss`
  - `train_part preserve loss`
  - `val_diff loss`
  - `val_part preserve loss`

## 当前建议

- 默认保持 `part_preserve_loss_weight=0.0`，不改变当前 LG-FrankenMotion baseline。
- 如果后续实验发现 Part R@1 / R@3 明显下降，可尝试：

```powershell
python train_part.py dataset=frankenstein-dataset diffusion.part_preserve_loss_weight=0.01
```

- 建议优先比较以下设置：
  - `0.0`
  - `0.005`
  - `0.01`
  - `0.02`
- 论文写法上将其称为 weak part-level controllability preservation regularizer，不作为主贡献。
