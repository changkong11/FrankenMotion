## 各组消融含义

### Group 3: w/o Local Branch

关闭 `use_local_branch`，不再使用 part-wise local temporal encoder 和 part interaction encoder。模型只依赖 global branch 生成输出。

目的：验证每个身体部位独立的局部时序建模是否对 part-level controllability 有贡献。

重点观察：

- Parts Avg R@1 / R@3
- 单个 body part 的 retrieval 指标
- FID / MM-Dist 是否明显退化

### Group 4: w/o Global Branch

关闭 `use_global_branch`，只保留 local part branch。模型将各个 part token 的平均结果作为最终协调特征。

目的：验证全局动作语义、整体轨迹和身体协调是否需要 global branch。

重点观察：

- Action R@1
- Caption R@1
- FID / MM-Dist
- TorsoLimb / FootSkate / Transition

### Group 5: w/o Local-Global Fusion

保留 local branch 和 global branch，但关闭 `use_local_global_fusion`。此时不使用 `part_to_global_attn` 和 `global_to_part_attn`，只用简单的 global token + local summary 进入 coordination projection。

目的：验证性能提升是否来自 local-global 双向交互，而不是仅仅来自模型容量增加。

重点观察：

- Full LG 相比该组在 Parts Avg R@1 和 coordination metrics 上是否更好
- Jerk / FootSkate / TorsoLimb 是否体现交互带来的协调性收益

### Group 6: w/o Temporal Refine

关闭 `use_temporal_refine`，不再使用 residual TCN refinement head。

目的：验证 temporal refine 对时序平滑、动作连续性和接触稳定性的贡献。

重点观察：

- Jerk，越低越好
- FootSkate，越低越好
- Transition，越低越好
- FID 是否受影响

### Group 7: Part Preserve Loss

保持模型结构不变，只调整 `diffusion.part_preserve_loss_weight`。这个 loss 只在有有效 part prompt 的帧上，对对应 body-part motion feature 额外计算 MSE。

目的：验证轻量的 part-level controllability preservation regularizer 是否能提升 part-level 对齐，同时不明显损害整体生成质量。

建议权重：

```text
0.0
0.005
0.01
0.02
```

重点观察：

- Parts Avg R@1 / R@3 是否提升
- FID / MM-Dist 是否下降
- Jerk / FootSkate 是否变差

## 训练命令

推荐先激活项目环境：

```powershell
conda activate frankenmotion
```

如果不想依赖当前 shell 环境，也可以显式使用：

```powershell
C:\anoconda\envs\frankenmotion\python.exe train_part.py ...
```

### Group 3: w/o Local Branch

```powershell
python train_part.py dataset=frankenstein-dataset data.preload=false run_suffix=_abl_no_local diffusion.denoiser.use_local_branch=false
```

### Group 4: w/o Global Branch

```powershell
python train_part.py dataset=frankenstein-dataset data.preload=false run_suffix=_abl_no_global diffusion.denoiser.use_global_branch=false
```

### Group 5: w/o Local-Global Fusion

```powershell
python train_part.py dataset=frankenstein-dataset data.preload=false run_suffix=_abl_no_lg_fusion diffusion.denoiser.use_local_global_fusion=false
```

### Group 6: w/o Temporal Refine

```powershell
python train_part.py dataset=frankenstein-dataset data.preload=false run_suffix=_abl_no_refine diffusion.denoiser.use_temporal_refine=false
```
